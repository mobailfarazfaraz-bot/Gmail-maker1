# Gmail ساز — پروژه آماده ساخت APK

## ساخت APK با GitHub Actions
1. این ZIP را در رایانه استخراج کنید.
2. تمام محتویات داخل پوشه را در ریشه مخزن GitHub آپلود کنید؛ خود فایل ZIP را به‌تنهایی آپلود نکنید.
3. مطمئن شوید پوشه مخفی `.github/workflows` نیز آپلود شده است.
4. در مخزن، تب Actions را باز کنید.
5. گردش‌کار `Build Gmail Maker APK` را انتخاب و در صورت نیاز روی `Run workflow` بزنید.
6. پس از موفقیت، وارد اجرای workflow شوید و از بخش Artifacts فایل `GmailMaker-debug-apk` را دانلود کنید.
7. ZIP دانلودشده را باز کنید؛ فایل `app-debug.apk` داخل آن است.

## امکانات
- دریافت نام و نام خانوادگی
- پیشنهاد نام کاربری و رمز عبور
- کپی آدرس و رمز
- باز کردن صفحه رسمی ثبت‌نام گوگل

این برنامه حساب گوگل ایجاد نمی‌کند، آزاد بودن نام کاربری را تضمین نمی‌کند و CAPTCHA یا تأیید امنیتی را دور نمی‌زند. ثبت‌نام و تأییدها باید توسط کاربر در سایت رسمی گوگل انجام شوند.
